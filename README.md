# مشروع البطة السمينة 🦆
### مؤسسة كمال أبو علي للمحاماة والاستشارات القانونية بالتعاون مع SHIFT Agency

تطبيق ويب متكامل عالي الأداء مبني باستخدام **Next.js 16 (App Router)** و **Tailwind CSS** ومصمم وفق أحدث معايير **UI/UX Pro Max**.

المشروع يترجم استراتيجية تسويقية وقانونية ذكية لفض الاشتباك وحرق الميزانيات، وفصل تجربة الزائر إلى مسارين رئيسيين:
1. **قطاع الشركات والمصانع (B2B)**: حماية استباقية للعقود، استشارات سنوية (Retainers)، ونموذج تأهيل متقدم للشركات مع مشغل سكريبت فيديو البوب كمال (60 ثانية).
2. **قضايا محكمة الأسرة والأفراد (B2C)**: استجابة فورية، خصوصية مشفرة بنسبة 100%، واتصال مباشر وواتساب للحالات الطارئة والنزاعات الأسرية.
3. **لوحة استراتيجية SHIFT وحاسبة العائد (ROI)**: حاسبة تفاعلية تقيس الوفر المالي الذي تحققه الشركة من تفادي النزاعات التعاقدية.

---

## ⚡ المميزات والتقنيات (Features & Stack)

- ⚡ **Framework**: Next.js 16 (App Router, Turbopack)
- 🎨 **Styling**: Tailwind CSS (Dark Obsidian theme, Glassmorphism, Neon Glow)
- 🔤 **Typography**: خط Cairo العربي من Google Fonts مع دعم كامل لـ RTL First
- 🔊 **Micro-interactions SFX**: مؤثرات صوتية تفاعلية دقيقة مبنية عبر Web Audio API (دون أي ملفات صوتية خارجية)
- 🎬 **Interactive Video Pitch Player**: مشغل تفاعلي لسكريبت فيديو كمال أبو علي مع Timeline Scrubber وموجات صوتية مرئية
- 📱 **Mobile & Desktop First**: تجاوب كامل على جميع مقاسات الشاشات

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل سيرفر التطوير
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في متصفحك.

---

## ☁️ النشر على Vercel (Deployment on Vercel)

المشروع مهيأ 100% للنشر بضغطة زر واحدة على منصة **Vercel**:
1. افتح حسابك على [Vercel](https://vercel.com).
2. اضغط **Add New Project** واختر مستودع GitHub: `deabow/presentation`.
3. سيتعرف Vercel تلقائياً على إعدادات Next.js (`Framework: Next.js`).
4. اضغط **Deploy**.
